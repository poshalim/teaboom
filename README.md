# Карточка товара «Ананасовый улун»

Верхняя часть карточки товара для [Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun): фото, категория, название, выбор фасовки, артикул, цена и старая цена, кнопка «В корзину» и короткое описание.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере.

Либо из папки проекта:

```bash
python3 -m http.server 8080
```

Страница будет доступна на `http://localhost:8080`.

## Поведение

У каждой фасовки сразу видны артикул, старая цена, актуальная цена и скидка. Выбранная фасовка дополнительно подсвечивается, а цена у кнопки «В корзину» меняется вместе с ней.

Фотографии листаются стрелками, миниатюрами и свайпом. Клик по снимку открывает его на весь экран. У кнопки «В корзину» есть обычное состояние и состояние при наведении. Корзина и сервер не подключены: нажатие только показывает, что позиция выбрана.
